These parts of the app exist on screen or in the menus but do not work yet. Please do not rely on them.

| What | What you see |
|---|---|
| **Sign up with Google** | A message, "Coming soon". Use your mobile number. |
| **Scan tab for employees** | A message, "Scanner unavailable". It says the feature is under service. |
| **Some scanner actions** | **Transfer**, **Damage**, **Waste**, **Receive Here**, **Transfer From Here**, **Register Serial**, and viewing a location lead to a page that does not exist. |
| **Auto check-in switch** | No setting in the app. The gate does check you in on its own when it detects you, but you cannot switch that off. |
| **Employee payslip view** | There is no screen to see your own payslip. |
| **Search across the app** | There is no global search. |
| **Calendar** | The department can be ticked, but there is no calendar screen. |
| **Template screen** | If an alert about a task opens a screen showing "This app includes example code to help you get started.", that is a leftover sample screen. Go back to Home. |

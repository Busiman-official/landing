## What each role can do

| Feature | Admin | Manager | HR | Employee |
|---|---|---|---|---|
| Sign in with mobile number | Yes | Yes | Yes | Yes |
| Log out of the app | Yes | No | No | No |
| Log out an employee / **Allow login again** | Yes | No | No | No |
| Team dashboard on Home | Yes | If branch has Attendance or Inventory | If branch has Attendance | Only if attendance officer |
| Employee dashboard on Home | No | Otherwise | Otherwise | Yes (unless attendance officer) |
| Self check-in (gate or remote) | No | Yes | Yes | Yes |
| Approve or reject remote check-ins | Yes | Yes | Yes | No |
| **Mark attendance** / **Clear attendance** for others | Yes | Only if attendance officer | Yes | Only if attendance officer |
| **Access & permissions** switches | Yes | No | No | No |
| **Add new employee** | Yes | No | No | No |
| Scan tab | Yes | Yes | Yes | No |
| Sales counter list | Yes | Yes | Yes | Own counter only |
| New enquiry | Yes | Yes | Yes | With **Leads management** |
| Create a service job | Yes | Yes | No | Yes |
| Assign technicians | Yes | Yes | No | No |
| Material approvals | Yes | Yes | No | No |
| **Switch kit** | Yes | Yes | No | No |
| Approve or reject expenses | Yes | Yes | No | No |
| **Employee advances** list | Yes | Yes | No | No |
| **My advances** | If any | If any | If any | If any |
| **Approve run** / **Send back for changes** / **Lock run** | Yes | No | No | No |
| Parties > **Outsourcing** tab | Yes | Yes | No | No |
| Company management, Payment methods, Gate devices, Locations | Yes | No | No | No |
| **My calling extension** | Yes | No | No | No |
| Virtual numbers | If your company has them | If your company has them | If your company has them | If your company has them |
| **Change password** | Yes | Yes | Yes | Yes |

All department-based features also need the matching department to be switched on for your branch. Admins pass every department check. "Attendance officer" is a flag an admin can give to any person.

## Screens by tile

| Tile or control | Needs department |
|---|---|
| Sales | Sales |
| Service, Kit, Create service report | Service jobs |
| Expenses | Expenses |
| Purchases | Purchases |
| Parties | Sales, Service jobs or Purchases |
| Inventory | Inventory |
| Payroll | Payroll |
| Approvals, Your Employees, marking others, floating pill | Attendance |
| Check In button on employee Home | Not tied to a department in the app (the server decides) |

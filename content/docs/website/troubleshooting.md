## What you may see and what to do

| What you see | What it means | What to do |
|---|---|---|
| A plain page with a large "404" and a message that the page could not be found. It has no buttons or menu. | The address is wrong, the page does not exist, or a report link no longer works. | Check the address for typing mistakes. Go to busiman.org. For a report link, ask the business for a new link. |
| A plain page that says the page could not load and a server error happened, with a **Reload** button | The site had a problem, or a report could not be loaded. | Tap **Reload**. If it still fails, try again later. For a report, ask the business to check the link. |
| The full-screen Busiman logo stays on screen and covers the page | The website needs JavaScript, a browser feature, and it is turned off. | Turn JavaScript on in your browser settings, then reload the page. |
| The splash screen flashes on a return visit | This is normal. | Nothing to do. |
| The **Download** button is missing from the top bar on your phone | The top bar hides it on phones and some other narrower screens. | Tap **Download** in the main banner, or scroll to the **Download** section. |
| **Features** is missing from the top bar on your phone | Same reason. | Use **Features** in the footer. |
| You tap **Windows**, **macOS** or **Android** and land on another page instead of starting a download | The website sends you to a general page when it cannot find the newest file. The label does not change. | If no download starts, contact team@busiman.org or +91 75006 73358. |
| Android: no download starts | See the line above. | Contact team@busiman.org or +91 75006 73358 and ask for the installer. |
| Windows shows an "unknown publisher" warning | The Windows app is not code-signed yet. | Click **More info**, then **Run anyway**. |
| The version number is missing under the download buttons | The latest version could not be checked just now. | The buttons still open, but they may take you to a download page instead of starting the download. If no download starts, contact team@busiman.org or +91 75006 73358. |
| A docs page says **Partially available** | Some parts of that feature are not ready yet. | Read the page to see what works now. |
| You cannot find "Delete account" in the menu | It is not in the header or footer. | Go to busiman.org/delete-account. |
| A report's company logo is missing or broken | The business's logo did not load. | The rest of the report is fine. |

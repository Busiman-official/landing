The Documentation explains how to set up and run the Busiman apps. Open it with **Docs** in the footer. The landing page is titled "Documentation". It says: "Everything you need to set up and run Busiman, on the desktop app and on mobile." It shows one card for each group of pages, and each card lists its pages.

## What is in the Documentation

The pages are in six groups.

- **Getting Started:** what Busiman is, installing it, first login and organisation setup.
- **Attendance:** how check-in and check-out, approvals, gate devices, shifts and history work.
- **Desktop App Guide:** how to use the Busiman desktop app, chapter by chapter.
- **Mobile App Guide:** how to use the Busiman mobile app, chapter by chapter.
- **Using the Website:** how to use busiman.org itself.
- **Security & Privacy:** how Busiman keeps your information safe, with one page each for the desktop app, the mobile app and the website.

Pick the group for the app you use. Each group starts with an overview page.

## Finding a page

- **On a computer:** a list of all pages sits on the left side.
- **On a phone or other narrower screen:** tap **Browse docs** above the page to open the list of pages.
- Use the cards on the Documentation landing page.
- Use **← Previous** and **Next →** at the bottom of each page.
- There is no search box in the Documentation. To find a word on a page, use your browser's own "find on page" feature.

## What each page shows

- A **badge** at the top that says **Available now** or **Partially available**. Partially available means some of the feature is not ready yet.
- A **platform tag**: **Desktop**, **Mobile** or **Desktop & Mobile**. This tells you which app the page is about.
- The page title, a short description and the guide itself.
- A thin amber bar under the top bar that fills as you read.
- **On this page**: a list of the headings on the page. Tap one to jump to it.
- **← Previous** and **Next →** at the bottom, to move through the guide in order.

Where **On this page** appears depends on your screen:

| Screen | Where "On this page" is |
|---|---|
| Wide computer screen | A column on the right that stays in view |
| Smaller screens | A fold-out box below the article, above Previous and Next. Tap it to open. |

## Which badge and tag each page has

Every page has a status badge and a platform tag.

- **Partially available:** Install on Mobile, Gate Devices & Office Verification
- **Desktop tag:** the Desktop App Guide pages, plus Install on Desktop, Organization Setup and Shifts
- **Mobile tag:** the Mobile App Guide pages, plus Install on Mobile
- **Desktop & Mobile tag:** the Using the Website pages and the other Getting Started and Attendance pages

## Useful facts from the Documentation

- **What is Busiman** has a table that shows which modules are on desktop and which are on mobile. Sales and Purchases are desktop-only for now. Inventory and Call Management are mobile-only. Calendar is desktop-only. Check this table before you plan how your team will work.
- **Install on Mobile** says Sales and Purchases are not on mobile yet.

| I want to... | Do this |
|---|---|
| Download the app | Tap **Download** in the main banner, or go to the **Download** section |
| Install on Windows | **Windows**, then **More info**, then **Run anyway** if you see the warning |
| Install on macOS | **macOS**, open the `.dmg` file, drag Busiman into **Applications** |
| Install on Android | **Android** in the **Mobile** card |
| Get on iPhone | Not yet. It says **Soon**. |
| See features | **Features** in the footer, or in the header on a computer |
| Read setup guides | **Docs** in the footer |
| Read articles | **Blog** in the footer |
| Read the FAQ | The "Questions owners ask before they start" section on the home page |
| Call | +91 75006 73358 |
| Email | team@busiman.org |
| Read privacy or terms | **Privacy Policy** or **Terms** in the footer |
| Delete my account | busiman.org/delete-account, then email team@busiman.org |
| Save a service report | **Download PDF**, then choose **Save as PDF**. Turn off "Headers and footers". |

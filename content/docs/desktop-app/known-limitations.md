These features exist on screen but are not currently working in the desktop app. Use the workaround if one is shown. Otherwise the action is not currently available.

| Where | What does not work | Workaround |
|---|---|---|
| Inventory > Employee Kits | "Force return to warehouse" asks for a location in a small question box that does not work | None. Not currently available. |
| Calendar | Setting a task to **Blocked** or **Cancelled**, or reopening a Completed task, asks for a reason in a small question box that does not work | None. Not currently available. |
| Calendar | **Duplicate** and **Cancel Task** from the right-click menu | None. Not currently available. |
| Purchases > Returns | **Cancel draft return** | None. Not currently available. |
| Purchases > Returns | **Print** on a return does nothing | None. |
| Sales > Orders | The **Invoice** button is disabled. Use **Charge** to complete a sale, or create a **Quotation** for a proposal PDF. | Charge or Quotation |
| Sales > History | There is no separate invoice document. **Download invoice** in a row's menu only opens the sale's receipt print view. | Use that receipt. |
| Purchases > Order detail | **Create bill** is disabled ("Bills module coming soon") | None. |
| Attendance > My attendance | Shows only "Coming soon." | Use the Employee Dashboard to check in and out. |
| Attendance > Setup | Shows only "Wi-Fi, devices, and shifts - coming soon." | Use **Settings > Attendance** for Wi-Fi networks and **Settings > Workforce** for shifts. |

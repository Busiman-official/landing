Open **Calendar** to plan tasks, meetings and events. You need the Calendar module.

## Views

Use the switcher to choose **Day**, **Week** (Monday to Sunday) or **Month**.

## Items on the calendar

- Types: Task, Meeting, Event, Shift, Leave.
- Priority: Low, Medium, High, Urgent.
- Status: Planned, Tentative, Confirmed, In progress, Blocked, Completed, Cancelled.

## What you can do

- Add a task with the quick-add panel (or press **N**).
- Drag a task to another time.
- Right-click a task for its menu.
- Undo a recent change.
- Filter by status, priority, type, who it is assigned to, who assigned it, or a date range. Your filters are remembered on this computer.
- Busiman warns you about conflicts.

## Who can do what

| Role | Calendar actions |
|---|---|
| Admin and HR | Everything, including changing a status that others cannot |
| Manager | Reassign, reschedule and cancel for the team, and edit own or created tasks |
| Employee | Edit tasks assigned to or created by themselves |
| Inventory Approver | View only |

Calendar keyboard shortcuts work only when no task form or menu is open (see [Quick reference](/docs/desktop-app/quick-reference)).

Some changes (setting a task to Blocked or Cancelled, reopening, duplicating, or Cancel Task from the menu) do not currently work. See [Known limitations](/docs/desktop-app/known-limitations).

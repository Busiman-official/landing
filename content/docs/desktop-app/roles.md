Your role decides which screens and buttons you get. Your branch also decides which modules exist for you. The server (the Busiman system itself) makes the final decision, so a button that appears may still be refused for you.

## Roles

| Role | In short |
|---|---|
| Admin | Runs the company. Sees every module. Manages branches, staff and company settings. |
| HR | Manages staff, shifts, Wi-Fi networks and attendance. |
| Manager | Reviews team attendance and approvals. Works with the modules of the branch. |
| Employee | Checks in and out, and uses the modules assigned to them. |
| Inventory Approver | Approves stock counts. Has **no dashboard** in the desktop app (see below). |

An **Attendance Officer** is not a separate role. It is an extra duty an Admin or HR can give to an Employee so they can handle attendance for specific people.

## What each role sees

| Feature | Admin | HR | Manager | Employee |
|---|---|---|---|---|
| Own dashboard | Admin Dashboard | HR Dashboard | Manager Dashboard | Employee Dashboard |
| Manual Check In and Check Out | No (automatic only) | No (automatic only) | No (automatic only) | Yes, on the Employee Dashboard |
| Attendance overview of others | Yes | Yes | Yes | Only if made an Attendance Officer |
| Approve or reject attendance requests | Yes | Yes | Yes | No |
| Mark or clear attendance for others | Yes | Yes (with limits) | No | Only for people assigned as an Attendance Officer |
| Settings > Workforce | Yes | Yes | No | No |
| Settings > Company | Yes | No | No | No |
| **Logout** menu item | Yes | No | No | No |

The full role-by-feature table is in [Quick reference](/docs/desktop-app/quick-reference).

## Important things to know

- **Only an Admin sees a Logout item.** Everyone else has no way to sign out inside Busiman. See [shared-computer advice](/docs/desktop-app/everyday-tips).
- **Inventory Approver has no dashboard.** After signing in, the content area stays blank. The top bar still works, so click **Inventory** (if your branch has it) to reach stock counts.
- **Modules are per branch.** If you do not see Inventory, Sales, Purchases, Service or Calendar in the top bar, your branch or your account does not have that module. Ask your Admin or HR.

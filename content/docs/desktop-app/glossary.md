---
title: "Desktop Glossary"
description: "Plain-language meanings of the terms used in the Busiman desktop app."
status: "live"
platform: "desktop"
---

| Term | Meaning |
|---|---|
| **Admin** | The role that manages the whole company. |
| **Approved network** | A Wi-Fi or Ethernet connection your company counts as "at work". |
| **Attendance Officer** | An Employee who has been given extra duties to handle attendance for certain people. |
| **Branch** | One location or division of your company. |
| **BSSID** | The hardware address of one Wi-Fi access point. Optional when adding a network; it makes matching stricter. |
| **Check-in / Check-out** | Recording the start and end of your workday. |
| **Counter / Sales point** | A till where sales are made. |
| **CSV** | A simple spreadsheet file that opens in Excel. |
| **Draft** | Work you started but have not finished. |
| **MAC address** | The hardware address of a network adapter, used to identify an Ethernet connection. |
| **Module** | A part of Busiman, such as Inventory or Sales. |
| **Movement** | Any change in stock: coming in, going out, moving or adjusting. |
| **POS (point of sale)** | The screen used to sell at the counter. |
| **Proxy server** | A computer that passes requests along for other devices on the office network. |
| **Quotation** | A price proposal for a customer. |
| **Serial number** | A unique number for one individual item. |
| **Session (sales point)** | The period a counter is open for sales. |
| **SKU / Variant** | A specific version of a product, such as a size or colour. |
| **Variant** | One version of a product, such as a size or colour, with its own code. |
| **SSID** | The name of a Wi-Fi network. |
| **Tray** | The small icon area on your computer where Busiman keeps running when its window is closed. |

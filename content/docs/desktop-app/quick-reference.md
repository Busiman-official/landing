## Keyboard shortcuts

| Where | Keys | What it does |
|---|---|---|
| Anywhere | Ctrl+K (Cmd+K on Mac) | Open search. In the point of sale and purchase receipts it jumps to product lookup instead. |
| Inventory | Ctrl+R | Quick Receipt |
| Inventory | Ctrl+T | Quick Transfer |
| Inventory > Locations | / | Jump to the location search |
| Products list | Ctrl+N | New product |
| Creating a movement | Ctrl+S | Save draft |
| Creating a movement | Ctrl+Enter | Submit |
| Point of sale | Ctrl+Enter | Charge |
| Purchases | Ctrl+Shift+O | Link a purchase order to a receipt |
| Purchase receipt | Ctrl+Enter | Post |
| Purchase receipt | Esc | Close |
| Calendar | N | New task |
| Calendar | Esc | Close |
| Calendar | Left / Right | Previous or next day |
| Calendar | Ctrl+Left / Ctrl+Right | Previous or next week |
| Employee attendance page | Esc | Close |
